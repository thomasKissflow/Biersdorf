# 11 - Questions for BDF: tech / solution consultant lens

**Purpose.** A question backlog for the BDF CIQ discovery, written from the functional-architect point of view: every question turns an unclear or contradictory business rule into a decision we can build once and run for years. Each question carries our proposed default, so the consultant can simply confirm or correct it.

**Status.** Discovery only. Nothing is built. Prepared 2026-10-05 for call 1 with BDF's consultant (business-side, light technical questions welcome) and for call 2.

**Sources.** All six analysis files (01-06), the seven source notes and the raw dumps in `context/`. Citation codes follow `00-glossary.md`: [ReqDoc p.x §y], [BRM REQ-...], [FLM rN] / [FLM changelog rN] / [Feldkatalog rN], [KB ...], [CIA #n], [VQ '...'], [IKW p.n]. "See 04 C-06" etc. points to our own analysis IDs (04 = contradictions register, 05 = process edge cases, 06 = data/config edge cases, 01 = expected workflow, 02 = modules and data model, 03 = user base).

## How to read this

| Column | Meaning |
|---|---|
| ID | TQ-nn (tech questions). Ordered by theme, then by impact |
